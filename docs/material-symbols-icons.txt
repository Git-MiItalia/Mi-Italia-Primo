# Icon names baked into public/fonts/material-symbols-subset.woff2.
#
# Built as a deliberate SUPERSET: every quoted lowercase token anywhere in
# src/ that is also a real Material Symbols name, per the full list in
# node_modules/material-symbols/index.d.ts. That catches icons chosen in
# ways a narrower scan misses — gpp_bad, for instance, only ever appears as
# a ternary branch (Promotions.jsx: result.ok ? 'verified' : 'gpp_bad')
# and was absent from the first build of this font.
#
# Some entries are certainly not icons (csv, orders, today, outlet share a
# name with one). They are kept on purpose: a few unused glyphs cost bytes,
# a missing one renders its own name on screen forever.
#
# A scan of src/ CANNOT see every icon this portal renders. GET
# /boutique/support/quick-help returns an `icon` per article, and those names
# are data, not code: menu_book and track_changes arrived that way and rendered
# as the words "_BOOK" and "TRACK_CHANGES" across the Support sidebar. Backend
# icon names are therefore also passed through safeIcon() in lib/safeIcon.js,
# which falls back to a real glyph when a name is not in this list — this file
# is that list's source of truth, and the module reads from it.
#
# Regenerate: see src/styles/fonts.css.
